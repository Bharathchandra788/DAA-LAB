 The implementation of different sorting algorithms helped 
 us understand how each algorithm arranges data and how
 performance differs. We compared Bubble Sort, Selection Sort,
 Insertion Sort, Merge Sort, and Quick Sort by observing their
 execution time and time complexity. From this practical, we
 learned that simple sorting algorithms are easier to implement
 but are less efficient for large datasets, while advanced algorithms
